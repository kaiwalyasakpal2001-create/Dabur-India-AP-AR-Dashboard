# Dabur India – Accounts Payable & Accounts Receivable Analysis

## Project Overview

This project focuses on analyzing Accounts Payable (AP) and Accounts Receivable (AR) operations using Microsoft Excel and Power BI.

The project started with raw financial transaction data, followed by Excel-based analysis and summary creation, and finally the development of interactive Power BI dashboards.

**Tools Used:** Microsoft Excel | Microsoft Power BI | Pivot Tables | DAX

---

# 1. Microsoft Excel – Data Analysis & Summary

The first stage of the project involved working with raw AP and AR transaction data in Microsoft Excel.

### 1.1 Data Preparation & Organization
- Organized raw Accounts Payable and Accounts Receivable data.
- Reviewed transaction records and financial information.
- Prepared data for analysis and reporting.

### 1.2 Accounts Receivable (AR) Analysis
- Total Invoice Amount
- Total Amount Received

- Total Invoice Count

### 1.4 Net Cash Position
